👋 First Time Here? Start Like This

If you’re part of the L1/L2 team, this is how you should naturally use the system during your daily work.

The goal is simple: Understand → Fix → Learn → Prevent

🔍 Step 1: Start with Incident Analyzer

  • Search for the issue you’re facing
  • The system analyzes and shows:
    • Impact and priority
    • Suggested troubleshooting steps
    • Similar past incidents
Key Feature: If the issue already exists, you’ll see previous Jira tickets.
This helps avoid creating duplicate tickets and speeds up resolution.

🛠 Step 2: Use Copilot (When Needed)

  • If you need deeper understanding or alternative approaches
  • Ask Copilot for:
    • Detailed troubleshooting steps
    • Possible root causes
    • Fix recommendations

Think of Copilot as your assistant—it helps you move faster, but you still validate the steps.

🧠 Step 3: Generate RCA After Fix

  • Once the issue is resolved, go to RCA Generator
  • Provide:
    • What happened
    • What you observed
    • What fixed it

The system will generate a structured RCA with root cause, resolution, and preventive actions.

This ensures the same issue is easier to handle next time—or avoided completely.

🚨 Step 4: Use System Advisor (Proactive View)

  • Use this when you want to look beyond a single issue
  • Ask questions like:
    • "Is the system stable right now?"
    • "What should we fix to prevent future issues?"

Unlike Analyzer (which is issue-specific), System Advisor looks at overall system health and patterns.

Analyzer = Solve current issue
Advisor = Prevent future issues

How to Use IntelliIQ

This tool is designed to help you analyze issues, fix them faster, and prevent them from recurring.

Use Copilot to solve the problem.
Use RCA Generator to ensure it doesn’t happen again.

🔧 Handling a New Issue

  • Start with Incident Analyzer → understand impact and similar past issues
  • Use Copilot → ask how to troubleshoot or fix
  • Apply the suggested steps and validate

Copilot gives direction—it doesn’t replace your judgment.

🧠 After Fixing the Issue

  • Go to RCA Generator
  • Provide:
    • Issue summary
    • Observed behavior
    • Fix applied

This generates a structured RCA including root cause, resolution, and prevention.

You’re not just fixing the issue—you’re building reusable knowledge.

🔁 Handling Recurring Issues

  • Use Analyzer → check past incidents
  • Identify patterns and frequency
  • Use Copilot to refine troubleshooting

🚨 Using System Advisor

  • Ask questions like:
    • "Is the system stable right now?"
    • "What should we fix to prevent issues?"
  • It analyzes recent incidents and gives actionable insights

✅ Best Practices

  • Validate Copilot suggestions before applying
  • Always generate RCA for important issues
  • Focus on patterns, not just individual tickets
  • Use System Advisor proactively

🎯 Final Thought

Fix fast. Learn faster. Prevent next.
